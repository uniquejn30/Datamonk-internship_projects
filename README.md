## 🚀 What is DataMonk

DataMonk is a learning platform offering structured learning paths (“Paths”) in cutting-edge tech domains. Each path contains one or more courses. Key paths include:

| Path | What you learn |
|---|---|
| **Foundations** | Essentials: tools & concepts you need before diving into advanced topics. |
| **Gen AI (In progress)** | Building agentic Retrieval-Augmented Generation (RAG) applications with OpenAI, LangChain, LangGraph; with fundamentals in FastAPI and Pydantic. |
| **Data Engineering** | Learning from Python basics to distributed data systems with real-world tools used by data engineers. |
| **DevOps** | Deployment, cloud infrastructure, automation (GitHub Actions, Terraform, Ansible, Kubernetes), scaling apps. |

> Source: [DataMonk All Paths](https://learn.datamonk.dev/paths)
